## 🚀 Proyectos

### 💈 Totem Barberstudio

Proyecto web desarrollado para una barbería con el objetivo de facilitar la gestión y reserva de citas de los clientes.

**Tecnologías y conceptos utilizados:**

* HTML
* CSS
* Integración con Setmore
* Gestión de citas
* Diseño de interfaz web
* Experiencia de usuario

El proyecto busca facilitar el proceso de reservación para los clientes y ayudar a la barbería a administrar sus citas.
